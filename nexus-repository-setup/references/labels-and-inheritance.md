# Template Labels

The template includes these labels in `.github/settings.yml`:

| Label | Description |
|-------|-------------|
| `bug` | Something isn't working |
| `feature` | New feature or request |
| `task` | Planned implementation work item |
| `documentation` | Documentation improvements |
| `code` | Source code changes |
| `dep` | Dependency updates |
| `config` | Configuration changes |
| `pinned` | Exempt from stale bot |

**Note:** Do not remove the `task` label — it's used by org issue templates.

# Inherited Files

These files are inherited from `<org>/.github/` when not present:

| File | Inherited? |
|------|------------|
| `PULL_REQUEST_TEMPLATE.md` | Yes |
| `.github/ISSUE_TEMPLATE/*` | Yes |
| `CONTRIBUTING.md` | Yes (fallback) |
